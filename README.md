# 📊 Customer Behavior Analysis — E-Commerce

An end-to-end data analytics project analyzing **customer shopping behavior in an e-commerce business** using Python, SQL, and Power BI.

The project focuses on understanding customer purchasing patterns, product/category performance, customer demographics, subscription behavior, and key business metrics.

---

## 📌 Project Overview

Understanding customer behavior is important for e-commerce businesses to improve sales, customer engagement, and decision-making.

In this project, customer shopping data was analyzed using **Python for data cleaning and exploratory analysis, SQL for business-oriented data analysis, and Power BI for interactive visualization and reporting**.

### 🎯 Objectives

* Analyze customer purchasing behavior
* Understand sales and revenue patterns
* Analyze product category performance
* Compare customer behavior across different age groups
* Analyze customer subscription status
* Identify useful business patterns and trends
* Build an interactive Power BI report
